# SlncTrZ-MCP v0.4.5

Date: 2026-10-10

This patch prepares the Prediction Seam cancellation fixes after v0.4.4. Source preparation is not stable publication or a live gateway upgrade; check the published GitHub release and running build identity separately.

## User-visible changes

- Request cancellation no longer restarts or quarantines the shared provider. The optional Prediction Seam's recording/resolution deadlines therefore do not trigger CyberBrain recovery.
- Requests cancelled before dispatch or while queued retain their cancellation identity. Prediction outcomes are indeterminate rather than contradicted.
- Genuine provider faults still use the existing bounded recovery policy. Provider request deadlines and restart budgets are unchanged.
- Current guides distinguish published features, pending release gates and deployment-specific acceptance.

## Security-relevant changes

- Cancellation diagnostics are request-local; they do not create, overwrite or consume the shared provider's recovery incident or budget.
- No change to OAuth profile ceilings, tool authorization, provider credentials or Full context guards.
- Prediction Seam remains owner-opt-in, disabled by default, excludes CyberBrain/read-only calls and does not copy caller arguments or provider output.
- Recording and resolution remain individually bounded to one second and best-effort; failed learning does not replace the main tool result.
- Ed25519 publisher signature verification authenticates the manifest followed by artifact size/SHA-256 checks. Windows Authenticode signing is not claimed.

## Migration / restart / reauthorization

- No additional database or OAuth schema migration is introduced by this patch. Existing grants and provider credentials are retained.
- When upgrading from pre-v0.3.6 installations, `audit.sqlite3` receives an additive migration for bounded authorization reason/operation fields; this is an existing upgrade requirement, not a new v0.4.5 migration.
- Back up state/config coherently, update through the installed management command and restart when requested; refresh client tool discovery.
- Owner sessions, Full context receipts and managed tasks are process-local and must be recreated after restart. Gateway-only provider calls do not require gateway context receipts.
- Keep the installed launcher entrypoint and any required CA configuration. Source changes alone do not update the running gateway.
- No reauthorization is required solely for these fixes.

## Supported / prebuilt targets

- Linux x64; hosted public acceptance covers User Install. System Install claims require separate disposable-systemd-host evidence.
- Windows x64 User Install; Windows System Install/service remains unsupported.
- The fix commit passed Linux Node 22/24 and Windows Node 24 CI. The exact v0.4.5 candidate must separately pass native identity, protected signing, clean public installs and installed Chromium acceptance before stable promotion.

## Known limitations

- Prediction Seam measures transport success, not domain correctness. It can add up to two seconds per eligible call.
- Backend outages, deadline expiry, shutdown or lost responses can leave missing/unresolved predictions; a timed-out backend may already have persisted a record.
- A ready provider configured as `cyberbrain`, exposing prediction_record/prediction_resolve, is required. Shared credentials may attribute records to one trusted backend identity.
- Cancellation does not prove remote side effects were rolled back or not executed. Inspect uncertain mutation outcomes before retrying; the gateway does not replay cancelled calls.
- Named real-client OAuth, live service/keyring and deployed build acceptance require separate evidence.

## Rollback

- Disable `SLNCTRZ_PREDICTION_SEAM_ENABLED` to stop new learning while retaining normal provider calls.
- Rollback to v0.4.4 reintroduces the cancellation/recovery defects; keep the seam disabled on that version. Rollback to v0.4.3 removes the seam.
- These fixes do not change OAuth schema. Rollback to a pre-v3 binary still requires restoring coherent pre-migration state/config.
