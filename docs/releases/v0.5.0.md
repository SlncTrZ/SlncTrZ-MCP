# SlncTrZ-MCP v0.5.0

Date: 2026-10-08

This release adds connection-specific result delivery to the shared MCP gateway.

## User-visible changes

- Connections default to a checked StructuredContent checkbox, retaining existing text and complete structuredContent.
- Uncheck StructuredContent for FullContent: all tools also return the complete structured result as JSON text. Text-only clients can read core.exec stdout/stderr within existing output limits.
- Preserve existing text, image/audio/resource blocks, error flags and metadata.
- Store the setting per OAuth grant; reload it on each request and retain it through token refresh and gateway restart.
- Mode and checkbox changes save automatically. Rename with the edit icon and Enter; Escape cancels. SAVED appears only after server confirmation.
- Responsive desktop/mobile controls, pending/error feedback and reduced-motion support.
- Merge Windows uninstall probe and disposable CI verification-key branch history.

## Security-relevant changes

- Result delivery does not alter authorization, tool visibility, consent ceilings or output limits.
- Owner result-delivery updates use the existing authenticated, CSRF-protected API.
- Mandatory publisher signature verification is retained: Ed25519 manifest verification precedes artifact SHA-256 and size checks. Windows Authenticode signing is not claimed.

## Migration / restart / reauthorization

- Stop the gateway and back up state/config together before upgrade.
- OAuth schema remains v3. An additive grant_result_delivery table stores preferences; existing grants default to StructuredContent without reauthorization.
- For pre-v0.3.6 installations, `audit.sqlite3` receives an additive migration for bounded authorization reason/operation fields.
- Restart after updating. Recreate process-local context receipts, tasks and Owner sessions; changes to result delivery apply to subsequent requests.
- Delivery is selected explicitly in Connections; OAuth redirect URIs do not select it.

## Supported / prebuilt targets

- Linux x64 User/System install.
- Windows x64 User install; Windows System Install/service remains unsupported.
- Node 22/24 source CI and native Windows Node 24 validation gate publication.

## Known limitations

- FullContent repeats structured data as text and can increase response size and token usage.
- Existing tool output truncation and bounds still apply.
- Text-only clients must consume the appended JSON text; client rendering can differ.
- Hosted uninstall probes are diagnostic fixtures, not a new uninstall implementation.
- Installed target acceptance and protected signing must pass before stable promotion.

## Rollback

- Restore a coherent pre-upgrade backup if rolling back across an older OAuth schema.
- The additive presentation table leaves OAuth v3 authority unchanged; older v3 binaries ignore the preference.
- An older binary returns its existing content format and does not implement FullContent.
