# SlncTrZ-MCP v0.4.3

Date: 2026-10-10

This release updates the Owner dashboard, removes agent bootstrap requirements from Gateway-only connections, and fixes account-folder and provider-credential resolution.

## User-visible changes

- Unified responsive Owner, Usage and Debate navigation with a compact sidebar, release version, bundled font and a single moving navigation indicator.
- Compact Overview with offline MeiLin artwork, rotating greetings and a brighter full-page activity Orb. Text is at least 12px; reduced-motion and hidden-page handling are retained.
- Durable workspace display name with inline editing. Preference-read failures show local feedback without blocking authenticated dashboard data.
- Provider detail drawer with tools, filtering, Test/Sync actions and confirmed Disable/Remove. Switching providers clears stale details immediately; session and generation guards isolate asynchronous actions.
- Gateway-only connections do not require agents to run context.bootstrap or supply a context receipt. Full connections retain their bootstrap requirements.
- Resolve account home/config folders across Linux and Windows without cold PowerShell module loading in native Windows folder discovery.
- Resolve provider bearer credentials from systemd credential references.

## Security-relevant changes

- Gateway-only retains its authorization ceiling and cannot promote itself to Full. Removing bootstrap guidance does not expand filesystem, command or provider authority.
- Owner APIs retain authentication, CSRF protection and display-safe provider details; credentials are not exposed in the drawer.
- Mandatory publisher signature verification is retained: Ed25519 manifest verification precedes artifact SHA-256 and size checks. Windows Authenticode signing is not claimed.

## Migration / restart / reauthorization

- Stop the gateway and back up state/config together before upgrade.
- OAuth schema remains v3; existing grants and result-delivery preferences are preserved. Workspace display-name storage is additive.
- For pre-v0.3.6 installations, `audit.sqlite3` receives an additive migration for bounded authorization reason/operation fields.
- Restart after updating and refresh MCP tool discovery. Recreate process-local Owner sessions, tasks and Full context receipts; Gateway-only does not require bootstrap.
- Existing grants do not require reauthorization for these presentation changes. Earlier finite grants are not silently converted into durable Gateway-only grants.

## Supported / prebuilt targets

- Linux x64 binary with User/System install paths. Hosted release acceptance covers clean User Install.
- Windows x64 User Install; Windows System Install/service remains unsupported.
- Node 22/24 source CI and native Windows Node 24 gates precede publication.

## Known limitations

- Named real-client OAuth/Gateway-only consent, discovery, refresh, reconnect and revoke acceptance is pending installation of this release on live.
- Live service/keyring credential acceptance is pending. Source tests and hosted clean installs do not certify an operator's service or keyring configuration.
- Installed target acceptance and protected signing must pass before stable promotion.
- Task runtime and context receipts remain process-local; restart clears them.
- FullContent retains existing output bounds and can increase response size.

## Rollback

- Stop the gateway and restore a coherent state/config backup when rolling back across an older OAuth schema.
- A v0.4.2 binary ignores the additive workspace display-name preference and restores its earlier dashboard and bootstrap guidance.
- Rolling back to pre-v3 binaries requires restoring pre-migration state/config; binary-only rollback is insufficient.
